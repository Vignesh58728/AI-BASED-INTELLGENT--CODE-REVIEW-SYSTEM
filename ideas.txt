## 🧠 15 Socratic AI Mentoring Strategies (Thinking > Answers)

1.  **The "Question Over Answer" Rule**: Any AI response must lead with a question (e.g., "What happens to your variable after the loop finishes?").
2.  **Progressive Hinting System**:
    - *Hint 1*: Broad conceptual clue (e.g., "Think about how you store data").
    - *Hint 2*: Logical step (e.g., "Would a Hash Map help you find elements faster?").
    - *Hint 3*: Pseudo-code (No actual code, just logic steps).
3.  **The "Find the Bug" Challenge**: Instead of fixing a bug, the AI highlights a line and says, "There's a logical flaw here. Can you spot why it fails for negative numbers?"
4.  **Concept Mapping**: AI mentions a related concept the user already knows (e.g., "This is just like the 'Array' logic we used in the School module").
5.  **Analogy-Based Learning**: Explaining complex code via real-world analogies (e.g., "Sorting is like organizing a library with only one empty shelf").
6.  **The "Why" Prompt**: If a user writes something inefficient, the AI asks, "I see you used a nested loop. What made you choose that over a single pass?"
7.  **Edge Case Puzzler**: AI provides a specific input that will break the user's code and asks, "How would your code handle 'None' or an empty list?"
8.  **Visual Logic Builder**: AI asks the user to describe the algorithm's flow in 3 text-based steps before they start typing.
9.  **The "One Thing at a Time" Focus**: AI ignores 5 bugs and focuses on the most fundamental one first to avoid overwhelming the user.
10. **Refactoring Quiz**: After a user solves it, the AI asks, "Great job! Now, how can we remove 3 lines from this while keeping the same logic?"
11. **Complexity Predictor**: Ask the user: "Before I calculate it, what do you think the Time Complexity of your solution is?"
12. **The "Missing Piece" Hint**: AI shows a 5-step logic list and leaves Step 3 blank for the user to figure out.
13. **Comparative Analysis**: "User B solved this using a Stack. How would a Stack change the way you access your items compared to your current Array?"
14. **Silent Observer Mode**: The AI only speaks if the user has been idle or deleting code for more than 3 minutes.
